# Mathias Cordova | Personal Trainer

Landing page estática para presentar los servicios de entrenamiento online y presencial de Mathias Cordova.

## Desarrollo local

Abrí `index.html` en un navegador. El sitio usa HTML y CSS, sin dependencias ni proceso de compilación.

## Publicar en GitHub Pages

En el repositorio, abrí **Settings → Pages**, elegí **Deploy from a branch**, seleccioná la rama que quieras publicar y la carpeta **/(root)**. GitHub Pages servirá `index.html` como página de inicio.

Las fotografías y las tipografías se cargan desde Unsplash y Google Fonts; el resto del sitio es estático y no requiere servicios externos.
